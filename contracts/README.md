# ZeroPass Contracts

This directory contains the Compact smart contract source files for ZeroPass.

## Files

| File | Description |
|---|---|
| `shadow-kyc.compact` | Main ZeroPass contract — ZK credential circuits |
| `hello-world.compact` | Minimal Compact reference contract |
| `managed/ZeroPass/` | Compiled artifacts — generated by `npm run compile` |

## Compiling

### Install Compact Compiler (0.31.1)

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh
compact update 0.31.1
```

### Compile

```bash
npm run compile
# Outputs: contracts/managed/ZeroPass/{contract,keys,zkir}/
```

Expected output:
```
Compiling 4 circuits:
  circuit "approveCredential" (k=13, rows=4459)
  circuit "issueCredential"   (k=13, rows=2281)
  circuit "proveEligibility"  (k=13, rows=2631)
  circuit "revokeCredential"  (k=13, rows=4459)
```

## Privacy Model

- `localSecret()` — private ZK witness, never transmitted
- `persistentHash<Bytes<32>>(_secret)` — the on-chain commitment (public)
- Observers see: commitment hashes, eligibility counter
- Observers cannot see: the underlying secret or user identity
